ℹ️ Cara Kemaskini Data Dashboard

Dashboard versi HTML ini menggunakan data yang tertanam terus dalam fail index.html.

Untuk kemaskini data, buka index.html dalam editor teks, cari bahagian const DATA = [...] di dalam tag <script>, dan ubah nilai status serta peratusan mengikut keperluan.
